01骨骼是什么

骨骼是 Minecraft 实体模型的骨架系统。下面这张图是大多数类人生物的骨骼层级: 根骨骼(root)作为锚点, 子骨骼依次挂载, 形成"父动子随"的联动。

骨骼层级结构

骨骼(Bone)是实体模型的骨架。每个骨骼像一块积木, 携带 位置(position)、旋转(rotation) 和 缩放(scale) 三种变换属性, 并挂在父骨骼之下形成层级结构。动画的本质, 就是随时间改变这些骨骼的旋转/位移/缩放曲线——骨骼动了, 挂在它上面的几何(像素方块)跟着动。
  • 根骨骼(root) — 模型的锚点, 整个身体从这里展开
  • 父骨骼 / 子骨骼 — 子骨骼继承父骨骼的全部变换, 父骨骼旋转, 子骨骼跟着旋转
  • 动画驱动 — 动画文件通过骨骼名引用骨骼, 例如 head、right_arm
  • 变量联动 — 基岩版用 Molang 变量(如 query.life_time)把骨骼运动与游戏状态绑定

基岩版骨骼与动画

  • JSON 数据驱动 — 几何模型 .geo.json 定义骨骼, 动画 .animation.json 定义动作
  • Molang 变量 — variable / query / temp / math 四类变量驱动骨骼
  • 动画控制器 — animation_controllers 用状态机切换动画
  • 提取范围: 几何模型 113 个 · 实体定义 180 个 · 控制器状态 344 个

Java版骨骼与动画

  • 代码定义 — 模型类用 addOrReplaceChild() 构建骨骼树
  • Keyframe 动画 — AnimationDefinition.Builder 定义关键帧
  • LayerDefinition — 103 个模型类提供可复用图层定义
  • 提取范围: 模型类 140 个 · 动画定义类 16 个

02Molang 变量系统

基岩版动画中的骨骼运动由四类变量驱动。以下是在全部动画中实际出现过的变量名(不去重统计):

variable

自定义变量, 动画之间传递状态(攻击时间、站立动画等)

variable.attack_time · variable.stand_anim
query

查询游戏与实体状态(存活时间、移动速度、视线角度)

query.life_time · query.modified_move_speed
temp

临时变量, 仅在单个动画表达式内生效

temp.idle_time · temp.random_rot
math

数学函数, 对数值做三角函数、取整、钳制等运算

math.cos · math.sin · math.clamp
